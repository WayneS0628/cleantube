# CleanTube

> **A Quick Note on the Code:** I did not write the code for this project. CleanTube was entirely generated by Claude. I conceptualized it as a personal tool to help me block out distractions and focus strictly on what I need to get done, and I used Claude to actually build it. 

## Why This Tool Exists
In an era of rapidly declining attention spans, protecting our ability to focus is more important than ever. After reading *Deep Work* by Cal Newport, I took a step back and rethought the influence my digital environment has over my attention and my ability to go deep. 

YouTube is an incredibly powerful tool for learning and research, but its default interface is heavily engineered to hijack your focus. The algorithm, the endless recommendations, and the home page feed are all designed to keep you clicking. I needed a way to use YouTube purely as a utility, without giving it control over my attention. I had Claude create CleanTube so I could reclaim my focus.

## What is CleanTube?
CleanTube is a distraction-free gateway that allows you to utilize YouTube's massive library and great features—without any of the addictive elements.

- **No Main Page:** You won't be greeted by a wall of algorithmic thumbnails designed to distract you.
- **No Recommendations:** Say goodbye to endless scrolling and rabbit holes.
- **Search-Only Interface:** You use CleanTube exactly like a search engine. You arrive with an intention, search for exactly what you need, find it, and move on.

## How It Works
CleanTube acts as a minimalist, lightweight wrapper. Built as a single `index.html` file, it bypasses the standard YouTube homepage completely. It provides a clean input interface where you can type your query, and it securely routes your search directly to the results, cutting out the homepage feed entirely. 

## How to Use

CleanTube is hosted publicly via GitHub Pages, so there is nothing to download or install. 

1. **Visit the site:** Go to [https://waynesimmonsjr.com/cleantube/](https://waynesimmonsjr.com/cleantube/).
2. **Search with intention:** Type what you are looking for into the search bar and hit enter. 
3. **Pro-tip:** For the best distraction-free workflow, bookmark the URL or set it as your browser's default homepage/new tab page so you always start with a clean slate.
